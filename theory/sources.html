9  Источники

9.1 Книги

The Linux Command Line Уильяма Шоттса объясняет командную среду Unix, файловое дерево, обработку текстовых потоков. В курсе используется Seventh Internet Edition, 25.12A. Примеры для fish сопровождаются ссылками на документацию этой оболочки. [54]

Learn Windows PowerShell in a Month of Lunches Дона Джонса даёт основу объяснения команд, справки, объектов, конвейера. Книга 2011 года описывает Windows PowerShell; современные команды курса опираются на документацию PowerShell 7. Книга Джеймса Петти, Дона Джонса, Джеффри Хикса «Изучаем скриптинг PowerShell за месяц» дополняет разбор сценариев, преобразования типов, форматирования, диагностики. [31], [57]

Pro Git Скотта Чакона, Бена Штрауба объясняет историю версий, состояния репозитория, ветвление, обмен, сопровождение проекта. Номера страниц относятся к русскому электронному экземпляру второго издания версии 2.1.124-4-gbef0ce5 от 24 августа 2026 года. Точные страницы книжных фрагментов указаны возле соответствующих объяснений. [3]

9.2 Командная среда

Синтаксис fish уточняется по документации версии 4.9.3. Для файловых операций, объектов, обработки CSV, потоков диагностики используются страницы Microsoft Learn для PowerShell 7.5. Запуск pwsh, политика выполнения сценариев, снятие блокировки загруженного файла описаны по страницам PowerShell 7.6. Версия сохранена в адресе соответствующего источника. Текстовые операции опираются на документацию GNU Coreutils 9.11 и GNU Grep 3.12.

Исторический контекст интерактивной работы даёт статья авторов CTSS. Деннис Ритчи описывает развитие Unix, в том числе управление процессами, появление каналов. Замысел объектной оболочки изложен в Monad Manifesto Джеффри Сновера; история документа представлена в публикации Microsoft 2007 года. [4], [32], [53], [55]

9.3 Управление версиями

Официальные руководства Git уточняют действие команд, способы адресации состояний, представление различий. Ссылки на конкретные руководства приведены возле примеров.

Глава об обмене использует документацию GitHub: адреса удалённых репозиториев, подготовка ключа SSH, регистрация открытого ключа, проверка соединения. Подпись при аутентификации пользователя определена в RFC 4252, §7. Транспортный протокол, проверка подписи сервера описаны в RFC 4253, §§7–8. Доверие ключу GitHub устанавливается по официальным отпечаткам.

9.4 Сопровождение проекта

Документация Git определяет работу дополнительного рабочего дерева, применение патча, создание тега, передачу версии, получение архива снимка. Страницы GitHub описывают ограничения для больших файлов, хранение содержимого через Git LFS, совместную работу с LFS. [27], [28], [29], [30]

Современные случаи рассмотрены по первичным публикациям. Статья Anthropic от 13 октября 2026 года, обновлённая 15 октября, посвящена устройству работы с собственным монорепозиторием. Статья GitHub от 6 октября, обновлённая 7 октября, описывает серверную инфраструктуру при росте нагрузки от агентов. Руководство Visual Studio Code показывает разделение двух делегированных задач по рабочим деревьям. [1], [2], [56]
