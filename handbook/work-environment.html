2  Рабочая среда

Пути. Файловые операции. Справка. Запуск сценария. Диагностика.

Примеры выполняются из lab. Исходные input/room A.txt и reports/input/room A.txt содержат соответственно north и south. Выберите один маршрут: PowerShell 7 / Windows либо fish / Linux. Модель пути разобрана в теории.

2.1 Рабочий каталог

Действие PowerShell 7 / Windows fish / Linux
Версия оболочки $PSVersionTable.PSVersion fish --version
Текущий каталог Get-Location pwd
Переход во вложенный каталог Set-Location -LiteralPath reports cd reports
Переход к родителю Set-Location -LiteralPath .. cd ..
Список элементов reports Get-ChildItem -LiteralPath reports ls reports
Вложенные каталоги Get-ChildItem -LiteralPath reports -Recurse ls -R reports

. обозначает текущий каталог, .. — родительский. Абсолютный путь включает корень, например C:\course\lab или /home/student/lab. Запись C:lab зависит от текущего расположения на диске C:. Папка, открытая в редакторе, не меняет каталог уже работающей оболочки. [10], [13, сс. 7–15]

2.2 Чтение файла

Маршрут Команда
PowerShell Get-Content -LiteralPath '.\input\room A.txt'
fish cat './input/room A.txt'

Обе команды выводят north. Кавычки сохраняют пробел внутри одного значения пути. Из lab/reports путь input/room A.txt выбирает файл со строкой south; путь ../input/room A.txt выбирает исходный north. В записи PowerShell разделители можно представить как \.

2.3 Создание каталога

Маршрут Команда
PowerShell New-Item -ItemType Directory -Path work
fish mkdir work

В текущем каталоге появляется work; до вызова такого имени нет. Параметр -ItemType получает значение Directory, которое выбирает каталог.

2.4 Файловые операции

Источник существует, каталог work создан, файлы назначения отсутствуют. Команды в каждом маршруте выполняются из lab по порядку.

  • PowerShell 7 / Windows
  • fish / Linux
Copy-Item -LiteralPath '.\input\room A.txt' -Destination work\selected.txt
Move-Item -LiteralPath work\selected.txt -Destination reports\selected.txt

-LiteralPath задаёт источник, -Destination — назначение.

cp './input/room A.txt' work/selected.txt
mv work/selected.txt reports/selected.txt

Первый аргумент задаёт источник, второй — назначение.

Копирование сохраняет исходный файл. Перемещение убирает прежнее имя work/selected.txt; новое reports/selected.txt содержит north. Существующий каталог назначения принимает файл внутрь себя; замена существующего файла зависит от команды. Перед действием проверьте путь назначения и соответствующее описание справки. [8], [13, сс. 29–32]

2.5 Удаление

Объект PowerShell 7 / Windows fish / Linux
Файл work/scratch.txt Remove-Item -LiteralPath work\scratch.txt rm work/scratch.txt
Пустой каталог work Remove-Item -LiteralPath work rmdir work
Состав каталога со скрытыми именами Get-ChildItem -LiteralPath work -Force ls -a work

В ls -a имена . и .. обозначают каталог и родителя. Удаление этими командами не перемещает файл в корзину менеджера. Перед удалением каталога установите отсутствие вложенных элементов; rmdir отказывается удалять непустой каталог. [12], [13, сс. 33–34]

2.6 Файловый шаблон

Требование PowerShell 7 / Windows fish / Linux
Одно имя с пробелом -LiteralPath '.\input\room A.txt' './input/room A.txt'
Выбрать имена по образцу Get-ChildItem -Path '.\input\*.txt' ls input/*.txt

В PowerShell шаблон интерпретирует параметр -Path; -LiteralPath принимает буквальное имя. В fish незаключённый в кавычки шаблон раскрывается до запуска команды. Кавычки в обоих маршрутах сохраняют пробел внутри значения. [2], [7], [8]

2.7 Справка

Цель PowerShell 7 / Windows fish / Linux
Найденная команда Get-Command Get-ChildItem type ls
Описание Get-Help Get-ChildItem -Full ls --help, man ls
Рекурсивный режим Get-Help Get-ChildItem -Parameter Recurse раздел -R в справке ls
Примеры Get-Help Get-ChildItem -Examples примеры документации утилиты

Get-Help Get-ChildItem -Online открывает официальную страницу, когда локальной полной справки нет. В fish help относится к оболочке; у внешней программы собственное руководство. Выход из man — клавиша q. [3], [9]

2.8 Запуск сценария

Учебный инструмент находится в tools; исходники двух вариантов предоставлены готовыми. Его аргументы — входной файл и новый отчёт. Вход reports/selected.txt содержит одну строку; reports/count.txt перед вызовом отсутствует. Текущий каталог — lab.

2.8.1 PowerShell 7 / Windows

Посмотрите политики по областям:

Get-ExecutionPolicy -List

Пример результата:

Область, от старшей к младшей Значение
MachinePolicy Undefined
UserPolicy Undefined
Process Undefined
CurrentUser Restricted
LocalMachine RemoteSigned

Undefined означает отсутствие настройки в области. Действует первое заданное значение сверху: в примере это CurrentUser / Restricted, сценарии запрещены. Если действующее значение задаёт MachinePolicy либо UserPolicy и оно равно Restricted, сценарии запрещены; AllSigned требует цифровой подписи. Учебный сценарий неподписан. При таком ограничении организации остановите запуск и используйте разрешённую учебную среду; изменение Process и Unblock-File его не снимают.

Для показанного состояния с незаданными групповыми политиками:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
Get-ExecutionPolicy

Второй вызов показывает RemoteSigned: настройка Process получила приоритет над CurrentUser. RemoteSigned разрешает локальные сценарии. Настройка действует в текущем сеансе и его дочерних процессах. При другом результате повторите Get-ExecutionPolicy -List и установите определяющую область; разрешённая среда согласуется до исполнения.

Прочитайте полученный из набора курса сценарий и проверьте источник. При действующей RemoteSigned неподписанный файл с меткой интернет-загрузки требует её снятия:

Unblock-File -LiteralPath .\tools\count.ps1

Команда изменяет метку файла, сохраняя действующую политику. [5], [11]

pwsh -NoProfile -File .\tools\count.ps1 `
  .\reports\selected.txt .\reports\count.txt
$LASTEXITCODE
Get-Content -LiteralPath .\reports\count.txt

-File выбирает сценарий, следующие два пути становятся его аргументами. -NoProfile исключает загрузку профилей настройки PowerShell. Обратный апостроф завершает первую строку без последующего пробела и продолжает команду. Код последнего внешнего процесса доступен в $LASTEXITCODE. [4], [6]

2.8.2 fish / Linux

fish --no-config tools/count.fish reports/selected.txt reports/count.txt
echo $status
cat reports/count.txt

--no-config исключает настройки fish. После имени файла идут два аргумента сценария. echo $status следует непосредственно за вызовом, чтобы показать его код. [1], [3]

В обоих маршрутах инструмент выдаёт lines=1, код 0 и файл с этой строкой. Для повторного опыта выберите новое имя отчёта. При отсутствии входа получаются сообщение с его путём, код 2 и отсутствие нового отчёта.

2.9 Сохранение текста

В текстовом редакторе сохраните файл по нужному пути в UTF-8 без BOM, затем прочитайте его командой. LF обозначает перевод строки одним байтом; CRLF — парой байтов. Копирование сохраняет байты исходного файла. В созданном редактором файле кодировку и переводы строк выбирают при сохранении. Несохранённая вкладка существует в памяти редактора.

2.10 Диагностика

Наблюдение Проверяемая причина
Путь не найден Текущий каталог, точное имя, регистр, наличие родительских каталогов
Прочитан другой одноимённый файл Начало относительного пути
Видно прежнее содержимое Несохранённая вкладка или другой путь
Отказано в доступе Права на чтение или изменение выбранного файла
pwsh либо fish не найдены Установка программы и доступность её каталога через PATH
Запуск сценария заблокирован в Windows Политика выполнения, метка загрузки; условия раздела о запуске
Новый отчёт не создан Сообщение инструмента, код, существование входа и каталога назначения

Найденный путь программы показывают Get-Command pwsh и type fish. Работа с учебными файлами ограничена распакованным каталогом опыта.
