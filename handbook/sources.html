6  Источники

6.1 Командная среда

Записи файловых операций опираются на документацию fish 4.9.3, страницы Microsoft Learn для PowerShell 7.5. Объяснение файлового дерева связано с The Linux Command Line Уильяма Шоттса, Seventh Internet Edition, 25.12A. Точные страницы указаны возле примеров. [34]

Запуск pwsh, политика выполнения сценариев, снятие блокировки загруженного файла описаны по документации PowerShell 7.6. Для обработки CSV, сортировки объектов, потоков диагностики используются страницы PowerShell 7.5. Назначение кода завершения grep устанавливает руководство GNU Grep 3.12. [5], [22], [24], [32]

6.2 Управление версиями

Pro Git Скотта Чакона, Бена Штрауба даёт объяснение состояний репозитория, ветвления, обмена. Номера страниц относятся к русскому электронному экземпляру второго издания версии 2.1.124-4-gbef0ce5 от 24 августа 2026 года. Формы команд уточнены по официальным руководствам Git; адресные ссылки сопровождают операции. [1]

Подготовка GitHub опирается на документацию сервиса: создание аккаунта, создание ключа SSH, добавление ключа в аккаунт, проверка соединения. Для первого соединения используется отдельная страница отпечатков ключей GitHub.

6.3 Сопровождение проекта

Операции с дополнительным рабочим деревом описаны в руководстве git-worktree. Проверка патча, его применение, создание именованной версии, отправка изменений, подготовка архива опираются на руководства соответствующих команд Git. [6], [7], [12], [18], [19]
