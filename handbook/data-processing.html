3  Обработка данных

Команды используют знакомую ведомость частиц в пробах из демонстрационного набора. Текущий каталог — flowlab, каталог results уже существует. Выберите PowerShell 7/Windows с CSV либо fish/Linux с текстовыми записями.

3.1 Передача данных

Среда Передача через конвейер Диагностика
PowerShell Объекты из Success команды A поступают в B Error — отдельный поток
fish, внешние программы stdout программы A соединён со stdin программы B stderr — отдельный канал

В Unix номера stdin, stdout, stderr равны 0, 1, 2. < назначает stdin файл, > записывает stdout с заменой прежнего файла, >> дописывает, 2> сохраняет stderr. Обычный | соединяет stdout. В PowerShell номера Success и Error для перенаправления — 1 и 2. На границе процесса pwsh Error выдаётся в stderr. [4], [9, сс. 56–63]

3.2 Исследование объекта

$raw = Import-Csv -LiteralPath inputs/readings.csv -Encoding utf8
$raw | Get-Member

Import-Csv создаёт объект на запись. Заголовки задают имена свойств, их значения импортируются строками. Get-Member показывает тип, свойства и методы. Для отдельного объекта $item.Code выбирает значение свойства Code. [7]

3.3 Сортировка объектов

$selected = $raw |
    Where-Object { $_.State -ceq 'keep' } |
    ForEach-Object {
        [pscustomobject]@{
            Code = $_.Code
            Units = [int]$_.Units
        }
    } |
    Sort-Object -Property Units, Code -Culture en-US
Запись Действие
Where-Object { условие } Пропускает объекты с истинным условием
$_ Текущий объект в данном блоке
-ceq Сравнивает строки с учётом регистра
[int]$_.Units Получает целое число из корректной десятичной строки
[pscustomobject]@{ ... } Создаёт объект с заданными свойствами
Sort-Object -Property Units, Code Сравнивает Units, при равенстве — Code
Select-Object -Property Code, Units Создаёт проекцию из двух свойств

-Culture en-US задаёт культуру строкового сравнения. Для кодов описанного формата получается порядок A–Z и 0–9. [8]

3.4 Экспорт CSV

$selected | Export-Csv -LiteralPath results/selected.csv -Encoding utf8NoBOM

Экспорт получает объекты данных и записывает их свойства. Для PowerShell 7 служебная строка #TYPE по умолчанию отсутствует. utf8NoBOM означает UTF-8 без начальной метки. Существующий результат заменяется. Пустой вход этой команды создаёт файл нулевой длины.

Экранное представление задаётся отдельной ветвью:

$selected | Format-Table -Property Code, Units

Format-Table выдаёт инструкции оформления. Их экспорт сохраняет служебные свойства таблицы. До Export-Csv должны доходить объекты наблюдений. [6], пример 7

3.5 Текстовый отбор

grep '|keep$' inputs/readings.txt |
    env LC_ALL=C sort -t '|' -k2,2n -k1,1 |
    cut -d '|' -f1,2 > results/selected.txt
  • grep '|keep$' в обычном режиме GNU grep выбирает строки с окончанием |keep.
  • sort -t '|' -k2,2n -k1,1 выделяет поля по |, сравнивает второе численно, затем коды в первом при равенстве чисел.
  • env LC_ALL=C sort ... задаёт локаль C только этому запуску sort.
  • cut -d '|' -f1,2 оставляет поля 1 и 2 с разделителем между ними.
  • > results/selected.txt записывает stdout последней команды, заменяя прежний файл.

Формат входа: одна запись Code|Units|State на строку, LF, UTF-8 без BOM; внутри поля нет разделителя или перевода строки. Показанная цепочка использует именно этот простой формат. CSV с кавычками имеет отдельные правила разбора. [9, сс. 293–304]

3.6 Коды завершения

printf 'last=%s; stages=%s\n' "$status" "$pipestatus"

Сразу после конвейера $status содержит код последней команды, $pipestatus — коды всех стадий слева направо. Сохранение set -l stages $pipestatus позволяет прочитать их после следующих команд. Для GNU grep обычный отбор даёт 0 при найденных строках, 1 при пустой выборке, 2 при ошибке. Успешные sort и cut дают 0. [1], [2]

В PowerShell после запуска внешнего pwsh переменная $LASTEXITCODE содержит код этого процесса. Для своих сценариев результат задаётся exit 0 при успехе и выбранным ненулевым кодом при отказе. Сообщение командлета в Error само по себе ещё не определяет код отдельного процесса. [3], [5]

3.7 Запуск сценария

Полные разобранные сценарии: PowerShell и fish. Оба получают вход и результат, проверяют наличие входа до записи и выполняются из flowlab. Сценарии сохраняются в его корне.

  • PowerShell 7 / Windows
  • fish / Linux
pwsh -NoProfile -File .\Select-Readings.ps1 `
    -InputPath inputs/readings.csv -OutputPath results/selected.csv `
    2> results/selected.err
$LASTEXITCODE

Параметры объявлены через param. Test-Path -PathType Leaf проверяет файл, Write-Error выдаёт диагностику. Подготовка Windows дана в запуске сценария: действующая политика, приоритет областей, разрешённая среда и проверка скачанного файла перед снятием метки. -NoProfile исключает профили настройки дочернего процесса.

fish --no-config ./select.fish inputs/readings.txt results/selected.txt 2> results/selected.err
printf 'exit=%s\n' $status

$argv[1] и $argv[2] — первый и второй аргументы. test -f проверяет обычный файл. printf 'Входной файл не найден: %s\n' "$input_path" >&2 выдаёт диагностику. --no-config исключает файлы настройки fish.

Повторите вызов с no-match.* и затем с отсутствующим absent.*. Выходы — empty.* и missing.*; журналы — empty.err и missing.err. Успех даёт 0, включая пустую выборку. В разобранных сценариях отсутствующий вход даёт 1 и сохраняет прежнее состояние выходного пути. Для опыта missing.* первоначально отсутствует.

3.8 Сопоставление результата

В fish сравниваются точные текстовые записи:

diff -u expected/selected.txt results/selected.txt
printf 'comparison=%s\n' $status

Код 0 означает совпадение, 1 — различия, больший код — проблему сравнения. При совпадении вывод пуст. Порядок строк и LF входят в формат данного результата.

В PowerShell сравниваются записи после разбора CSV:

Import-Csv -LiteralPath results/selected.csv -Encoding utf8 |
    Format-Table -Property Code, Units
Import-Csv -LiteralPath expected/selected.csv -Encoding utf8 |
    Format-Table -Property Code, Units

Заголовок должен содержать ровно Code,Units в этом порядке. Сопоставьте число записей, значения и последовательность S07/2, S02/12, S11/12. Корректные CSV-кавычки и окончания LF/CRLF допустимы. Просмотр выбранных свойств дополняется проверкой полного заголовка.

Пустой результат проверяется размером файла: в PowerShell (Get-Item -LiteralPath results/empty.csv).Length, в fish wc -c < results/empty.txt. В обоих случаях ожидается 0.
