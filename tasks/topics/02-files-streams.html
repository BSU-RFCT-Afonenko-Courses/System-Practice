3.4.1 Условие

Выполните на своем ПК. В учебном каталоге создайте папку missing. Через справку найдите команду создания пустого файла и создайте missing/semester.txt. Запишите в него две отдельные строки: название курса и название своей оболочки. Перейдите в missing относительным путем, затем откройте тот же каталог абсолютным путем. Создайте рядом папку My Notes, скопируйте туда файл и переименуйте копию в semester-copy.txt. Сохраните использованные команды в commands.txt.

3.4.2 Источник и перенос

MM2020RU: Обзор курса + shell; Упражнения №1–4; Навигация по оболочке. Ссылка на оригинал или карточку издания.

Адаптированное авторское условие. Сохранены создание каталога, поиск справки, создание и построчное заполнение файла. /tmp заменен учебным каталогом, sh/curl-сценарий — обычным текстом; добавлены пути с пробелами, копирование и переименование. PowerShell использует собственные командлеты, Linux — команды из fish.

3.4.5 Условие

Выполните в терминале fish облачной рабочей области VS Code PrairieLearn. В выданном headers.txt находятся HTTP-заголовки. Прочитайте файл через стандартный ввод команды, передайте результат по конвейеру и сохраните строку Last-Modified в last-modified.txt. Вторым запуском допишите эту строку в тот же файл. Затем выполните чтение несуществующего файла и направьте сообщение об ошибке в errors.txt. Сохраните команды в commands.txt. Для повторения на своем ПК в Windows выполните ту же обработку в PowerShell 7 средствами его конвейера и перенаправления.

3.4.6 Источник и перенос

Адаптированное авторское условие. Вместо sh-сценария и сетевого запроса выдается сохраненный текст HTTP-заголовков. Добавлены дописывание и отдельное перенаправление ошибки; Linux выполняет интерактивные команды fish, а не Bash-сценарий. Локальный повтор необязателен.

3.4.9 Условие

Выполните на своем ПК. Получите папку source с двумя текстовыми файлами. Через справку найдите команды копирования, перемещения и переименования. Создайте папки work и My Notes. Скопируйте содержимое source в work, перенесите один файл в My Notes и переименуйте его. Перейдите в обе папки относительными и абсолютными путями. В Windows используйте PowerShell 7, в Linux — команды в fish.
