2.2.1 Условие

На своем ПК откройте папку учебной работы в VS Code и терминал: в Windows — PowerShell 7, в Linux — fish. Сохраните пустой файл команд с расширением .ps1 или .fish; найдите автодополнением доступную команду и откройте ее справку. В Windows используйте расширение PowerShell. Затем откройте выданную рабочую область VS Code в PrairieLearn и ее терминал fish. В обоих терминалах определите текущий каталог и версию оболочки; сохраните эти сведения в local-environment.txt и cloud-environment.txt соответственно.

2.2.4 Будущие материалы и способ сдачи

Понадобится доступ к подготовленной рабочей области PrairieLearn с VS Code, Git, fish и PowerShell 7 (pwsh); утилиты архивации для дополнительных заданий. Для Windows — установленные PowerShell 7, Git и VS Code с расширением PowerShell. Для Linux — VS Code, Git и fish; PowerShell-карточки доступны через облачный pwsh.

Облако: файлы в рабочей области VS Code PrairieLearn. Локально: те же файлы отдельными вложениями или одним ZIP-архивом.
