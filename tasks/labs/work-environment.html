2  Рабочая среда

Станция передала два файла измерений и рабочие записи. Подготовьте каталог результатов: текущие измерения должны быть доступны под согласованными именами, сведения о станции — в архиве. Запустите готовый инструмент проекта для подсчёта строк утренних измерений. Исходные измерения сохраняются.

Работа выполняется в одном маршруте: PowerShell 7 / Windows либо fish / Linux. Файловые операции и запуск инструмента выполняйте командами выбранного маршрута. Последовательность и записи команд выбирайте самостоятельно. Пояснение создаётся текстовым редактором; способ упаковки результата свободный.

Подготовка: рабочая среда и вводный разбор. Формы команд находятся в справочнике.

2.1 Исходные данные

Стартовый набор содержит каталог survey:

survey/
├── source/
│   ├── morning log.txt
│   └── evening.txt
├── tools/
│   ├── count.ps1
│   └── count.fish
└── work/
    ├── draft.txt
    └── scratch.txt
Файл данных Строки содержимого по порядку
source/morning log.txt A=12, B=7
source/evening.txt A=10, B=9
work/draft.txt station=west
work/scratch.txt temporary

Каждая указанная строка завершается LF; кодировка файлов — UTF-8 без BOM. Это обычные файлы и каталоги. В исходном наборе result и explanation.md отсутствуют. Распакуйте набор в собственную доступную папку. Область изменений — полученный каталог survey. Каталоги source, tools и их файлы сохраняют имена и содержимое.

2.2 Текущие измерения

Создайте в result/current две копии исходных измерений:

  • morning.txt содержит точную копию source/morning log.txt;
  • evening.txt содержит точную копию source/evening.txt.

Байты копий совпадают с исходными файлами: сохраняются значения, порядок строк и переводы строк. Копии получают файловыми командами выбранной оболочки.

2.3 Архив рабочей записи

Разместите содержание прежнего work/draft.txt в файле result/archive/station.txt. Байтовое содержимое сохраняется. Прежний путь work/draft.txt после преобразования отсутствует. Временная запись work/scratch.txt больше не нужна; удалите её и опустевший каталог work.

2.4 Отчёт программы

В tools находятся два готовых варианта инструмента из разобранного проекта. Выберите вариант своей оболочки. Написание и изменение его исходного текста в эту работу не входит.

Инструмент получает два пути: входной текст и новый файл отчёта. Каталог назначения должен существовать; файл отчёта до запуска должен отсутствовать. Инструмент сохраняет вход и создаёт одну строку lines=N, где N — число строк входного файла; такой же текст появляется в терминале. Успешное завершение имеет код 0. При отсутствующем входе он сообщает причину, возвращает 2 и не создаёт отчёт.

Запустите инструмент для result/current/morning.txt и получите result/line-count.txt. В файле должны находиться строка lines=2 и завершающий LF, записанные в UTF-8 без BOM. Прочитайте полученный файл и установите код завершения вызова. Подготовка запуска Windows разобрана в справочнике.

2.5 Пояснение

В корне survey создайте explanation.md в UTF-8. В нём укажите:

  1. Выбранную операционную систему, оболочку и её версию.
  2. Относительный путь из survey/result/current к исходному survey/source/morning log.txt. Объясните переходы между каталогами и способ сохранить пробел при передаче пути команде.
  3. Одну использованную команду и параметр, значение которого вы уточнили по справке. Приведите запрос справки либо точную ссылку на документацию и объясните влияние параметра.
  4. Команду запуска инструмента, её рабочий каталог, наблюдавшийся код завершения и соответствие полученного числа содержимому входа.

2.6 Предъявление результата

Предъявите ZIP-архив, в корне которого находится каталог survey целиком. Сам архив создаётся снаружи survey. Требуемое дерево:

survey/
├── source/
│   ├── morning log.txt
│   └── evening.txt
├── tools/
│   ├── count.ps1
│   └── count.fish
├── result/
│   ├── current/
│   │   ├── morning.txt
│   │   └── evening.txt
│   ├── archive/
│   │   └── station.txt
│   └── line-count.txt
└── explanation.md

Исходники сохраняются, копии и запись станции имеют требуемые байты, рабочие временные пути отсутствуют. Имена учебных файлов и регистр букв совпадают с условием. В result находятся перечисленные результаты. Проверьте дерево внутри созданного архива и прочитайте его текстовые файлы.

На разборе покажите чтение одного результирующего файла из выбранного каталога и объясните путь. Запуск инструмента предъявляется отдельно: покажите свой вызов с новым временным именем отчёта внутри survey, его код и результат; после демонстрации удалите этот временный отчёт.
