# Слияние изменений порога

Выберите PowerShell 7 на Windows либо fish на Linux. Нужны Git
и текстовый редактор. Распакуйте комплект в новую папку и найдите
`versioning/project`: исходные три файла предоставлены без `.git`.

Создайте историю по условию, выбирая последовательность команд
самостоятельно. A/B/F/D обозначают ваши собственные состояния;
их реальные идентификаторы запишите в `versioning/explanation.md`.
Сохраните короткое наблюдение рабочего и подготовленного изменения
либо приготовьтесь показать его на разборе.

Проверьте обе расходившиеся линии, двухродительское слияние,
итоговые 30 ms в секундах, неизменность measurements.tsv и чистую main.
Сохраните рабочую ветку. В пояснении разберите стороны конфликта,
перевод единиц и выбранный снимок.

Архивируйте каталог `versioning` целиком в ZIP или tar.gz, включая
`project/.git` и explanation.md. Создайте архив снаружи каталога,
распакуйте в новую проверочную папку и прочитайте историю и состояние.
У этой задачи один репозиторий project. Способы сохранения `.git`
при упаковке приведены в справочнике по ссылке из условия.
