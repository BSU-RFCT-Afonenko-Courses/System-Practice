# Подготовка выпуска

Комплект содержит локальный проект отчёта с двумя репозиториями Git
и входным патчем. Требуются Git, текстовый редактор и один выбранный
маршрут: PowerShell 7/Windows либо fish/Linux.

## Начало работы

Полное условие и открытые примеры доступны на странице задачи
«Подготовка выпуска» и в скачиваемом архиве условия
`exr-project-maintenance-release-conditions.zip`.
Для локального чтения распакуйте архив целиком в отдельную папку
и откройте `README.md`.

Распакуйте стартовый архив `project-maintenance-start.zip` из этого
комплекта в новую доступную папку. Корневой каталог `maintenance`
содержит обычный репозиторий `work`, соседний bare-репозиторий `shared.git`
и `incoming/review.patch`.

Имена учебных файлов и регистр букв сохраняйте по условию.
Последовательность допустимых действий выбирайте самостоятельно,
пояснение создайте текстовым редактором.

Откройте терминал в `work` и проверьте исходное состояние:
ветка `main` и тег `start` выбирают M, индекс и рабочее дерево чисты.
Начальные версии файлов и связь M/F с A приведены в условии.
Имя и почта автора настраиваются в `work`; адрес `origin` указывает
на соседний `shared.git` относительным путём. Дальнейшие действия
выполняются средствами Git.

## Материалы выпуска

`release.patch`, `report-2.0.zip` и `explanation.md` располагаются
в `maintenance` рядом с `work`. Патч воспроизводит полный снимок
выпуска на базе `start`, архив выпуска содержит этот снимок
под каталогом `report-2.0/`.

Короткие наблюдения обязательных приёмов и пояснение сохраняют основания
выбора базы патча, разрешения конфликта, отношений истории и проверки
переданного выпуска. Полный журнал терминала не требуется.

## Полная сдача

Упакуйте всю `maintenance` в ZIP или tar.gz со скрытым содержимым
`work/.git` и полным `shared.git`. Выходной архив создаётся рядом
с `maintenance`. Способ полной упаковки выбирайте самостоятельно.
После извлечения в новую папку проверьте дерево, прочитайте файлы и историю
обоих репозиториев, проверьте состояние `work`, исходные теги,
ветку P и материалы выпуска.

Способ полной упаковки приведён в доступном из условия справочнике.
`report-2.0.zip` содержит только файлы версии; история и наблюдения
передаются в полном архиве `maintenance`.
