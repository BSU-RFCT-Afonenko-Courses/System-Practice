# Каталог измерений станции

Выберите PowerShell 7 на Windows либо fish на Linux. Распакуйте комплект
в собственную доступную папку и найдите `survey`. Область файловых
действий — этот каталог; перед командой устанавливайте рабочий каталог,
от которого отсчитывается путь.

Выполните файловые преобразования из условия командами выбранной
оболочки. Имя `source/morning log.txt` содержит пробел: передавайте
его в составе одного пути. Уточните по справке один используемый
параметр и объясните его действие в `survey/explanation.md`.

Проверьте две точные копии в `result/current`, запись станции
в `result/archive/station.txt`, сохранность `source` и `tools`,
отсутствие прежнего `work`. Прочитайте полученные файлы.

Подготовьте ZIP с корнем `survey` снаружи этого каталога; проверьте
содержимое архива. Пояснение и чтение результата из выбранного каталога
предъявляются по условию. Способ выполнения команд выбираете вы.
