# Запуск счётчика строк

Выберите PowerShell 7 на Windows либо fish на Linux. Комплект содержит
готовый самостоятельный каталог `survey` с инструментами и входом
`result/current/morning.txt`. Распакуйте его в собственную доступную папку.

Запускайте `tools/count.ps1` в PowerShell либо `tools/count.fish` в fish.
PowerShell получает `SourcePath` и `ReportPath`; fish — входной путь
первым аргументом и путь нового отчёта вторым. Установите рабочий каталог
и согласуйте с ним оба пути. Для Windows используйте подготовку
локального сценария из справочника, указанного в условии.

Перед запуском каталог `result` существует, `result/line-count.txt`
отсутствует. Передайте утренние измерения инструменту, получите этот
отчёт, прочитайте его и установите код завершения. Ожидаются `lines=2`
в отчёте и терминале, код `0`. Сохраните исходный вход и оба инструмента.

Запишите среду, команду, рабочий каталог, код и смысл результата
в `survey/explanation.md`. На разборе повторите вызов с новым временным
именем отчёта и после чтения удалите временный файл.
ZIP с корнем `survey` создайте снаружи каталога.
