# Две выборки наблюдений

Выберите PowerShell 7 на Windows либо fish на Linux. Распакуйте комплект
с каталогом `processing`, сохраните `inputs` и `expected`.
Для PowerShell используйте CSV, для fish — текстовые файлы с разделителем `|`.

В корне `processing` создайте один сценарий своего маршрута:
`Select-Readings.ps1` либо `select.fish`. Оба результата строятся
за один вызов по правилам условия. Каждый использует содержательный
конвейер из не менее двух стадий отбора, сортировки или проекции.

Запускайте сценарий из корня `processing`, предварительно создав `results`.
Параметры PowerShell — `InputPath`, `SelectedPath`, `ExcludedPath`;
в fish передайте эти три пути в том же порядке позиционно.
Для Windows примените подготовку запуска из справочника, указанного
в условии. Команды и устройство сценария выбираете вы.

Выполните три случая из таблицы условия: основной вход, `no-match`
и отсутствующий вход. Укажите полные имена для выбранного расширения.
Направьте stderr каждого запуска в его журнал и установите код завершения.
Сопоставьте оба результата с открытыми `expected`: в fish побайтно,
в PowerShell по CSV-колонкам, значениям и порядку записей.
Пустая выборка в обоих маршрутах имеет ровно 0 байт.

В `explanation.md` запишите среду, команды, коды и объяснение стадий.
Проверьте состав `results`: четыре файла данных и три журнала,
без двух `missing`-результатов. ZIP с единственным корнем `processing`
создайте снаружи каталога. На разборе покажите применение правил
к согласованному допустимому набору.
