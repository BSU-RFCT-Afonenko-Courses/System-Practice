# System Practice

Курс о работе с проектом через командный интерфейс. Оболочка позволяет
запускать программы, преобразовывать данные, проверять состояние файлов.
Git сохраняет историю изменений, поддерживает параллельную работу
над проектом, передаёт изменения между репозиториями.
Курс предполагает опыт программирования; устройство командной среды
объясняется с исходных понятий.

Основные демонстрации выполняются в PowerShell 7 на Windows.
Для fish на Linux приведён полный альтернативный маршрут.
Студент выбирает один маршрут для практической работы.

## Учебные материалы

[Портал](index.qmd) связывает пять форм курса:

- [Теория](theory/index.qmd) объясняет понятия, устройство механизмов,
  условия их применения.
- [Лекции](lectures/index.qmd) состоят из двух презентаций:
  «Командный интерфейс», «Управление версиями».
- [Справочник](handbook/index.qmd) содержит записи операций для обеих оболочек.
- [Введения](practice/index.qmd) восстанавливают решение знакомого примера
  перед самостоятельной работой.
- [Задания](tasks/index.qmd) задают исходные данные, требуемый результат,
  правила сдачи.

Обязательны три лабораторные:
[«Рабочая среда»](tasks/labs/work-environment.qmd),
[«Обработка данных»](tasks/labs/data-processing.qmd),
[«Управление версиями»](tasks/labs/version-control.qmd).
В третьей работе студент создаёт историю проекта, объединяет ветки,
публикует репозиторий в GitHub по SSH, клонирует его по SSH во вторую
локальную копию. Условие предусматривает сдачу публичного или частного
репозитория. [«Сопровождение проекта»](tasks/optional/project-maintenance.qmd) —
добровольное продолжение с входным патчем, локальным обменом, подготовкой выпуска.
Канонические требования находятся в условиях работ.

## Сборка

Курс использует нативные проекты Quarto с профилями `student` / `full`.
Корневой проект собирает портал; пять подпроектов соответствуют учебным формам.
QRC разрешает ссылки между ними. Порядок сборки, зависимости, проверка
результата описаны в [технической документации](docs/README.md).
Сведения о локальной поставке общих инструментов находятся в [UPSTREAM](UPSTREAM.md).

Адрес курса: [System Practice](https://bsu-rfct-afonenko-courses.github.io/System-Practice/).
