# System Practice

Курс о командной среде, файлах, обработке данных и истории проекта.
Аудитория уже умеет программировать; оболочка, терминал и Git объясняются
с исходных понятий. Практическая работа использует один выбранный маршрут:
fish / Linux либо PowerShell 7 / Windows.

Новая редакция начата 16 октября 2026 года по принятому предметному плану.
Она состоит из пяти форм: `theory/`, `lectures/`, `handbook/`, `practice/`
и `tasks/`. Обязательная программа включает три лабораторные «Рабочая среда»,
«Обработка данных», «Управление версиями»; «Сопровождение проекта» —
добровольное продолжение.

## Материалы и работа над курсом

«Рабочая среда» и «Обработка данных» прошли независимую содержательную
приёмку. Авторский набор Git подготовлен к рецензии: состояние репозитория
и ветвление, две лекции, справочник, одно введение и самостоятельное
условие третьей лабораторной.
[Портал](index.qmd) связывает пять форм и показывает дальнейшую программу.
Добровольный проект создаётся следующим набором; прежние карточки
не задают количество и композицию новой редакции.

- [Действующие правила и состояние работы](docs/README.md).
- [Методика](docs/authoring-methodology.md) и [образцы](docs/authoring-examples.md).
- [Предметный план](docs/course-revision-plan.md).
- [Источники](docs/sources.md) и [фактическое чтение](docs/source-reading-log.md).

Учебный текст, данные и условия написаны автором по прочитанным источникам.
Полные книги не включаются в публичный сайт. Общая библиография хранится
в `bibliography/course.bib`. QRC связывает материалы пяти проектов;
канонические условия — [«Рабочая среда»](tasks/labs/work-environment.qmd),
[«Обработка данных»](tasks/labs/data-processing.qmd)
и [«Управление версиями»](tasks/labs/version-control.qmd).

## Техническая поставка

Курс использует нативные проекты Quarto и профили `student` / `full`.
Корневой проект собирает портал и подпроекты пяти форм. Сборочные hooks,
расширения, их версии и локальная среда обслуживаются технической ролью.
Результаты student/full и проверка ссылок относятся к конкретному снимку
исходников; прежний успешный CI не подтверждает новый набор.

Первая лабораторная передаёт локальный ZIP с данными, принимает ZIP
с каталогом результата и отдельное содержательное пояснение. Подготовка
архивов, эталонов, проверок и рабочих сред имеет собственную техническую
приёмку. Вторая лабораторная дополнительно принимает собственный сценарий,
результаты трёх запусков и объяснение конвейера. Третья принимает полные
локальные репозитории с историей, индексом и рабочими файлами, а также
объяснение выбранных переходов. Правильность файлов
и применение обязательного приёма проверяются раздельно.
Наличие PowerShell на Linux не устанавливает готовность Windows
workspace. Готовая облачная рабочая область VS Code и действующий grader
этим авторским набором не заявляются.

Адрес публикации курса:
[System Practice](https://bsu-rfct-afonenko-courses.github.io/System-Practice/).
Новая локальная редакция не объявляется опубликованной. Push, внешние PR,
merge, публикация сайта и изменение реального Moodle выполняются отдельным
поручением.
