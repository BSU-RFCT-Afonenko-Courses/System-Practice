# Выполнение общего плана на CachyOS

Для обоих курсов действует [единый общий агентский план](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/codex/task-publication-methodology-20261020/docs/task-publication-plan.md) в Java.
В нём находятся принятые решения 1–7, нормативные роли, фазы и проверки.
Скопируйте целиком раздел «Текст для нового чата» из
[общего стартового промпта](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/codex/task-publication-methodology-20261020/docs/task-publication-start.md).
Он получает актуальные базы [PR Java №18](https://github.com/BSU-RFCT-Afonenko-Courses/Java/pull/18)
и [PR System Practice №4](https://github.com/BSU-RFCT-Afonenko-Courses/System-Practice/pull/4),
сохраняет пользовательскую работу и запускает последовательное исполнение
агентами с явными модельными допусками.

Для System Practice сохраняются [методика](authoring-methodology.md#публикация-банка-заданий)
и [предметный контекст](course-revision-plan.md#публикация-банка-заданий-согласованный-порядок-от-20-октября-2026-года).
Установленный Gradle без Wrapper относится только к Java-задачам, которым
нужна система сборки. Повторное согласование решений 1–7 не требуется.
Оставшиеся попытки, баллы, веса и итоговая оценка уточняются перед зависимыми
действиями; независимая работа продолжается. Личные материалы прежней
машины не нужны. Windows/PowerShell, fish/Linux, GitHub по SSH и действующая
PrairieLearn имеют отдельные проверки и границы доступа по общему плану.
