# Продолжение публикации банка заданий на CachyOS

Общий [стартовый промпт для Java и System Practice](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/codex/task-publication-methodology-20261020/docs/task-publication-start.md)
хранится в репозитории Java. Передайте новому чату раздел «Текст для нового
чата» целиком: он предусматривает получение актуальных вершин обоих PR,
сохранение пользовательской работы и последовательное выполнение плана.

Для System Practice действуют [дополнение методики](authoring-methodology.md#публикация-банка-заданий)
и [порядок от 20 октября с открытыми вопросами](course-revision-plan.md#публикация-банка-заданий-согласованный-порядок-от-20-октября-2026-года).
Повторное общее утверждение правил не требуется. Открытый вопрос уточняется
перед зависящим от него действием; независимая работа может продолжаться.
Личные каталоги и локальные передачи прежнего компьютера для входа не нужны.
