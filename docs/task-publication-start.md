[Реестр решений](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/d8647f9b9509d9a78ac483717b1b852f574bae5d/docs/refactoring-plan.md) и [регламент](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/d8647f9b9509d9a78ac483717b1b852f574bae5d/docs/release-execution-regulation-20261103.md)

До роли подтвердите собственный запуск по [переносимой процедуре](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/d8647f9b9509d9a78ac483717b1b852f574bae5d/docs/model-admission.md).
Сохраните собственные chat/agent/original turn ID; после возобновления
и перед приёмкой проверяйте весь исходный интервал, включая вложенные
model/effort, без сдвига начала. При отсутствии подтверждения роль
останавливается. [Единая матрица](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/d8647f9b9509d9a78ac483717b1b852f574bae5d/docs/agent-execution-proposal-20261029.md) допускает только
`gpt-6.1-sol` и `gpt-6.1-terra` с явно назначенным effort. Автор и независимый
содержательный рецензент — разные Sol/high. Standard обязателен;
автоматическая подмена и глобальная перенастройка запрещены.

Актуальная исходная база SP — `d254c636bbc0701e881315802dc3a3f775b7d872`
из PR №11: семь задач и пять работ. Сохраняются PowerShell 7/Windows,
fish/Linux, оба действующих маршрута bundle/Workspace, GitHub по SSH,
учебные цели, оценивание и данные. Код пишет технический исполнитель.
У файла и контракта в одной фазе один владелец; своя работа независимо
не принимается. Старые пользовательские деревья и открытые PR сохраняются.

По [решению 79](https://github.com/BSU-RFCT-Afonenko-Courses/Java/blob/d8647f9b9509d9a78ac483717b1b852f574bae5d/docs/refactoring-plan.md#decision-79) SP выпускается в составе
Pages/PrairieLearn без обязательного перехода из Moodle. Сервер, Moodle,
сертификаты, аккаунты и личные ключи в текущую ночь не изменяются.
Source, render/export, runtime и серверная эксплуатация имеют отдельные
статусы. Тяжёлые локальные проверки последовательно выполняет только
интегратор N0; исполнители передают ему готовые коммиты и запрос проверки.
