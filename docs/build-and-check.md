# Локальная техническая сборка

Инструменты сборки предназначены для автора и преподавателя. Они не добавляют
Python, Quarto или JDK к требованиям студенческих заданий на сценарии и Git.
На проверенном CachyOS Task3.54 запускается командой `go-task`.

```sh
go-task install
go-task materials:check
go-task test:materials
go-task render
```

`install` проверяет текущую vendor-поставку по hashes. Получение новых
расширений этим действием не выполняется. Отдельный `install:from-sources`
требует заранее полученных exact provider checkouts; происхождение локальных
поправок описано в UPSTREAM и provenance.

`materials:check` проверяет исходные ZIP трёх лабораторных и публичные копии
демонстрационных наборов. Каждый самостоятельный Quarto project владеет
своими binary resources: поэтому теория и справочник получают идентичные
публичные копии из practice/materials. Это не отдельные варианты задания.
Канонические bytes и передаваемые Git commits сохраняются.

Для согласованного изменения объявленных данных служит `materials:write`.
Каждый упаковщик сначала сверяет свои назначения и предыдущие известные
хеши. Неожиданная локальная правка сохраняется с ошибкой, не перезаписывается.
Содержание учебного договора перед изменением данных требует авторского
согласования. `render`, `render:full` и `preview` зависят от проверки наборов.

`test:materials` проверяет факты файлов, ZIP, реальные Git index/trees/history,
вариативность допустимых решений и защиту локальных поправок. Файловые
checkers сохраняют manualRequired: смысл сценария, самостоятельность,
команды и объяснение графа по одним итоговым файлам не устанавливаются.
PowerShell/Git проверяются отдельно от fish grader. Локальный запуск на Linux
не подтверждает Windows, облачную рабочую область или реальный Moodle.

Новая сборка должна иметь receipt с исходным SHA и фактическими source hashes.
Результаты более ранней редакции сохраняются как исторические свидетельства.
Команда publish изменяет внешний сайт и выполняется только отдельным
разрешённым действием после предъявления конкретного результата.
