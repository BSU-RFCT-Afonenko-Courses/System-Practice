# Работа над курсом System Practice

Действующая редакция начата 16 октября 2026 года на базе
`fb2681e4847c85bea0c98c6fcfad7a442d1ff017`. Принятый единый handoff r3
разрешает новое авторство пяти учебных форм с опорой на книги, три основные
лабораторные и добровольный проект. Это вход для автора, рецензента
и технического исполнителя.

## Текущая стадия

Нормативный набор S0–S1 принят независимым содержательным рецензентом
после адресной правки объяснения конвейера PowerShell; снимок
`c4b3af399e8501e35c6c6998d2bc13697b8eda30`.

S2 «Рабочая среда» принят независимым содержательным рецензентом без P1/P2
на снимке `9cf24753fd20a58b93594c9aca49977675f4cd9c`. Последующая техническая
интеграция, включая пространства ссылок `system-practice-*`, зафиксирована
в `ab7b355ed31f893e17ea6711789a7a55fe3a43dd`.

S3а «Обработка данных» получил независимый содержательный PASS после
адресной правки самостоятельного преобразования S3-A1, снимок
`a460f0c749bf00f6cd1f532ca4cd85dbb390b4e0`. Демонстрация сохраняет одно
представление; самостоятельная работа получает два с разными порядками.

Подготовлен к рецензии S3б: состояние репозитория, история и ветвление
во всех пяти формах, две тематические лекции и третья лабораторная.
Дополнительное чтение Pro Git с точной пагинацией записано в журнале.
Портал связывает три основные лабораторные; добровольный проект остаётся
следующим авторским набором. Содержательный PASS S3б ещё не заявляется.

Техническая упаковка данных, проверки команд, render и проверка рабочих
сред имеют раздельные статусы. Windows workspace и новая публикация
авторским набором не подтверждены.

контракты. Реальный Moodle и внешняя публикация имеют отдельный этап.

## Передача между ролями

Автор сообщает файлы, учебный результат, фактическое чтение и модельный
интервал. Рецензент читает законченный набор и затронутые переходы.
Sol фиксирует технические проверки на конкретном source SHA. Общий журнал
координатора связывает свидетельства. Методика не подменяется сборкой
или перечнем файлов.
