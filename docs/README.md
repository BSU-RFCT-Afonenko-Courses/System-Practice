Действующая переработка от 19 октября 2026 года охватывает пять учебных
форм и ровно две лекции: «Командный интерфейс» и «Управление версиями».
Студенты входят в командную среду через знакомые файлы и каталоги.
Основные демонстрации используют PowerShell 7/Windows; fish/Linux имеет
полный практический маршрут. GitHub и SSH входят в обязательную третью
лабораторную. Три лабораторные и добровольный проект сохраняют небольшой
объём самостоятельной работы.

Исходный снимок новой работы — `97339ca2e61e9a3fbd0da6735cd7fb1554eefffd`.
Рабочая ветка — `codex/system-practice-two-lectures-20261019`;
рабочее дерево —
`/home/tolya/.codex/worktrees/system-practice-two-lectures-20261019/System-Practice`.
Координатор ведёт владение файлами, модельные интервалы и отчёты во внешней
области `/tmp/system-practice-revision-work-20261019/`. Приватные журналы
чатов и книги в репозиторий не переносятся.

Новый набор методики и образцов проходит независимую содержательную
и стилистическую рецензию до массового авторства. Его наличие в рабочем
дереве само по себе не устанавливает приёмку. Дальнейшие наборы проходят
тот же цикл; итоговые статусы и точные снимки находятся в отчётах координатора.
Прежний успешный CI, render или preview относятся к прежним исходникам.

Автор передаёт цель, файлы, точный снимок или хеши, фактическое чтение,
допустимые решения и открытые ограничения. Независимый Astra читает
законченные последовательности, notes и затронутые переходы. Sol проверяет
команды и фактическую выдачу на согласованном снимке. После интеграции
независимый Astra читает обе лекции целиком и связи пяти форм.

Windows, VS Code, GitHub по SSH и действующий Moodle получают отдельные
свидетельства. PowerShell на Linux подтверждает поведение своего запуска.
Локальная имитация remote подтверждает механизм обмена историей.
Готовность учебного маршрута Windows и внешнего доступа устанавливается
собственным испытанием.

## Внешние действия

Текущее прямое поручение разрешает после приёмки PR, merge в `main`
и публикацию `gh-pages`; за них отвечает координатор. Учебная инструкция
о регистрации GitHub не разрешает агенту создавать аккаунт или менять
личные ключи пользователя. Для внешнего опыта нужен отдельно разрешённый
тестовый аккаунт/репозиторий. Изменение Moodle и выпуск общих инструментов
в текущую учебную переработку не входят.
