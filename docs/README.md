# Работа над курсом System Practice

Действующая редакция начата 16 октября 2026 года на базе
`fb2681e4847c85bea0c98c6fcfad7a442d1ff017`. Принятый единый handoff r3
разрешает новое авторство пяти учебных форм с опорой на книги, три основные
лабораторные и добровольный проект. Это вход для автора, рецензента
и технического исполнителя.

## Текущая стадия

Подготовлен первый авторский набор S0–S1: нормативы, образцы и композиционная
карта. Прочитанные разделы четырёх включённых книг занесены в журнал.
Независимая содержательная приёмка выполняется отдельным рецензентом.
Следующий набор — первая законченная тема «Рабочая среда» с необходимым
объяснением путей и файлов, связями пяти форм и контрактом первой лабораторной.

Учебный корпус, настройки проектов и лабораторная поставка пока сохраняют
исходное состояние. Образцы содержат авторские команды; их запуск
в выбранных средах и перенос в QMD выполняются после передачи техническому
исполнителю. Новый render и новая публикация не заявляются.

## Исторические материалы

Корневой [README](../README.md), [UPSTREAM](../UPSTREAM.md), старые карточки
и `provenance/` фиксируют первую версию. Число карточек, прежние маршруты
и временные оценки относятся к её истории. До обновления корневого README
рабочим входом новой редакции является этот каталог. Перенос полезных целей
из старого банка выполняется по содержанию, без сохранения всех ID.

Техническая ветка `reference/pr-1-c712a0b` хранит пилот PrairieLearn одного
задания. Интеграционные решения оценивает Sol; новое условие определяет
автор. Проекты, история учебных репозиториев и проверки создаются под новые
контракты. Реальный Moodle и внешняя публикация имеют отдельный этап.

## Передача между ролями

Автор сообщает файлы, учебный результат, фактическое чтение и модельный
интервал. Рецензент читает законченный набор и затронутые переходы.
Sol фиксирует технические проверки на конкретном source SHA. Общий журнал
координатора связывает свидетельства. Методика не подменяется сборкой
или перечнем файлов.
